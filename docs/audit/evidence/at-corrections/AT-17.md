## 2. Detail bukti per lapisan

- **Status mahasiswa (API).** `case-boundary.test.ts` menguji transisi: sebelum deadline tanpa kiriman → `BELUM_MENGUMPULKAN` (+ `submittedAt: null`); setelah deadline tanpa kiriman → `TIDAK_MENGUMPULKAN`. `cases.test.ts` menguji hal sama dan menegaskan kiriman setelah deadline ditolak `409 DEADLINE_PASSED`. Logika di `cases.service.ts:37-39` hanya memilih status dari `before_deadline`; tidak ada jalur yang memberi `score` default 0.
- **Tidak ada nilai nol / kiriman palsu.** `assessments.test.ts:341` membuat topik + kasus yang sudah lewat deadline untuk dua mahasiswa, lalu memanggil daftar kiriman dosen: tiap baris `status = TIDAK_MENGUMPULKAN` dan `score = null`; query langsung ke tabel `submissions` menghasilkan `0`. Ini bukti terkuat untuk klausa "tanpa nilai nol atau kiriman palsu".
- **Android.** Enum `SubmissionStatus` memuat `TIDAK_MENGUMPULKAN`; `HomeScreen` memakai tone Danger dan string "Tidak mengumpulkan"; `StudentCaseScreen` merender `ClosedCase` (banner "Tenggat berakhir", judul "Tidak Mengumpulkan", "Tidak ada pengiriman") untuk status tersebut dan tidak menampilkan skor. `StudentTopicsScreen` menampilkan status kasus dari `materialAvailable`, bukan status pengumpulan — di luar cakupan AT-17.
- **Batasan bukti.** Semua bukti Android di atas berasal dari pembacaan source dan resource; tidak ada tes JVM, tes Compose, atau tangkapan layar emulator yang menjalankan keadaan setelah deadline.

## 3. Gap aktual (yang belum tertutup)

2. **Tidak ada tes komposabel/instrumen** yang merender `HomeScreen` atau `StudentCaseScreen` pada keadaan `TIDAK_MENGUMPULKAN`; `ClosedCase` dan kartu Beranda hanya diverifikasi lewat inspeksi kode.
3. **Layar nyata emulator NOT RUN.** Belum ada bukti UI nyata pasca-deadline; tidak ada screenshot di `compat-e2e/screens/` untuk keadaan ini.
4. **Assertion skor null belum eksplisit di detail mahasiswa.** `case-boundary.test.ts:155` memeriksa `status` (`TIDAK_MENGUMPULKAN`) dan `submittedAt: null`, tetapi tidak memeriksa `score`; assertion `score: null` ada pada daftar dosen (`assessments.test.ts:341`). Secara kontrak aman (`score: row.score`), tetapi satu assertion tambahan akan menutup celah ini.
5. **Staging NOT RUN.** Perilaku zona waktu/deadline di lingkungan nyata belum diuji.

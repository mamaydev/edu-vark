## Risiko & catatan

1. **FREEZE Gradle**: verifikasi final build/test Android pada working tree utama harus dijalankan serial setelah Lead mencabut freeze. Jalur kode sudah lolos `assemble`/unit test di worktree isolasi.
2. **Satu tes Android merah di working tree** (bukan scope Paket 1): `TopicRepositoryPaginationTest > deep pagination still accumulates all topics in order` (`TopicRepositoryPaginationTest.kt:91`) — suite Paket 5/PO; 95/96 tes lain PASS. Kegagalan `LoginViewModelTest`/`AdminCreateUserViewModelTest` terkait aturan ID Admin sudah diperbaiki pemiliknya selama proses berjalan.
3. **Unduh materi (AT-26)**: `GET /api/v1/material-files` memakai signed URL tanpa guard DB; perubahan ada di Paket 2. Selama belum diguard, kebutuhan "unduh ditahan saat wajib ganti password" belum terbukti end-to-end.
4. **Refresh race**: outcome `refresh` boleh 200 atau 401; yang dijamin dan diuji adalah tidak ada sesi yang hidup kembali setelah pencabutan (`activeSessionCount = 0`, token hasil rotasi ditolak). Ini sesuai desain `updateSessionTokens` yang tidak pernah mengaktifkan `is_active`.
5. **Enrollment ganda**: subquery `LIMIT 1` pada `enrollments` dilindungi unique index `(class_id, student_id)`, sehingga hanya ada satu baris status per mahasiswa/kelas.
6. **Database**: semua tes memakai `eduvark_test_p1` dengan `ALLOW_TEST_DB_RESET=1`; DB dev `eduvark` tidak di-TRUNCATE.
7. Tidak ada commit/push/PR; perubahan dibiarkan di working tree untuk direview Lead.
